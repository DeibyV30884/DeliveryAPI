Plataforma de delivery de comida con backend en **.NET** y frontend en **React**, con soporte para cuatro roles de usuario: administrador, cliente, repartidor y restaurante.

Características:
 
Autenticación JWT con roles diferenciados (administrador, cliente, repartidor, restaurante)
Gestión de restaurantes: registro, horarios, productos y menú
Gestión de pedidos: creación, previsualización de costos, seguimiento en tiempo real
Gestión de repartidores: asignación de pedidos, historial y estadísticas
Recarga de saldo para usuarios
Geolocalización: integración con Google Maps y OSRM para cálculo de rutas
Subida de imágenes de productos y restaurantes
Paneles y dashboards independientes por rol
